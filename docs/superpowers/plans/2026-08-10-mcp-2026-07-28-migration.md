# MCP 2026-07-28 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the linked-past MCP server to SDK 2.0 / spec revision 2026-07-28 and serve stateless Streamable HTTP (no `Mcp-Session-Id`).

**Architecture:** The SDK's `MCPServer` (renamed from `FastMCP`; identical decorator + lifespan API) speaks the 2026-07-28 revision and bridges 2025-era clients automatically. We keep the single shared `AppContext`, keep viewer routes on `_custom_starlette_routes` (verified working in 2.0.0, including `WebSocketRoute`), plumb the serving port through `AppContext` (v2 `settings` has no `port`), and run `streamable_http_app(stateless_http=True)` under uvicorn.

**Tech Stack:** Python 3.13, `mcp` 2.0.0, Starlette, uvicorn, pytest, httpx (already a transitive dep of `mcp`; add as explicit test import).

## Global Constraints

- Dependency pin: `mcp>=2,<3` (spec: "pin `mcp>=2,<3`").
- No tool signature or body changes beyond the `settings.port` fix.
- All 410 existing tests must pass; run with `uv run pytest` from repo root.
- Lint with `uv run ruff check .` before each commit.
- Verified 2.0.0 API facts (do not re-derive): `from mcp.server import MCPServer`; `from mcp.server.mcpserver import Context`; `MCPServer(name, instructions=..., lifespan=...)`; `streamable_http_app(streamable_http_path='/mcp', json_response=False, stateless_http=False, ..., host='127.0.0.1')` — no `custom_starlette_routes` param, but the `_custom_starlette_routes` list attribute exists and its routes (incl. WebSocketRoute) are included in the app; `mcp.settings` exists but has NO `host`/`port` fields; `_tool_manager.list_tools()` still works; `mcp.client.Client(server)` runs a server in-process including its lifespan; the stateless app enforces a Host allowlist via the `host` param (wrong host → 421 "Invalid Host header").

```python
"""Stateless Streamable HTTP regression tests (MCP 2026-07-28).

The server must not mint Mcp-Session-Id headers, and must still answer
2025-era handshake-based clients (SDK bridges the revisions).
"""

import asyncio

import httpx

from linked_past.core.server import build_http_app, create_mcp_server


def test_no_session_id_header(patched_app_context):
    """A legacy initialize POST gets a response with no Mcp-Session-Id header."""

    async def run():
        app = build_http_app(create_mcp_server(), host="testserver")
        async with app.router.lifespan_context(app):
            transport = httpx.ASGITransport(app=app)
            async with httpx.AsyncClient(transport=transport, base_url="http://testserver") as client:
                response = await client.post(
                    "/mcp",
                    json={
                        "jsonrpc": "2.0",
                        "id": 1,
                        "method": "initialize",
                        "params": {
                            "protocolVersion": "2025-06-18",
                            "capabilities": {},
                            "clientInfo": {"name": "legacy-test", "version": "0"},
                        },
                    },
                    headers={
                        "Accept": "application/json, text/event-stream",
                        "Content-Type": "application/json",
                    },
                )
                return response

    response = asyncio.run(run())
    assert response.status_code == 200
    assert "mcp-session-id" not in {k.lower() for k in response.headers}


def test_in_process_client_lists_tools(patched_app_context):
    """The SDK 2.0 in-process client can list tools without any session setup."""
    from mcp.client import Client

    async def run():
        mcp = create_mcp_server()
        async with Client(mcp) as client:
            result = await client.list_tools()
            return [t.name for t in result.tools]

    names = asyncio.run(run())
    assert "discover_datasets" in names
    assert "query" in names
```

Note: `patched_app_context` is the existing fixture used by `test_server.py` (patches dataset fetches so `build_app_context` works without network). If it lives in `tests/conftest.py` it is available automatically; if `test_server.py` defines its own fixture arrangement, mirror that arrangement here instead.
